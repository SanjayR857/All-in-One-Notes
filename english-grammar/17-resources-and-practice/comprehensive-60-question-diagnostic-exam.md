# Comprehensive 60-Question Diagnostic Exam: The Master Benchmark 🎓📝

> **Level:** CEFR A1–C2 (Comprehensive Evaluation & CEFR Placement)  
> **Primary References:** Council of Europe (*Common European Framework of Reference for Languages*); Diagnostic Assessment Syntheses of Raymond Murphy and Michael Swan  
> **Core Premise:** This 60-question diagnostic exam provides an objective, rigorous assessment of your English grammatical competence across the entire knowledge base. The questions range from elementary parts-of-speech recognition (A1) to complex negative inversion, subjunctive mood, and RFC 2119 precision (C2). Complete the exam without consulting notes, calculate your score, and consult the diagnostic score band for your tailored remediation roadmap.

---

## 1. Exam Instructions & CEFR Scoring Rubric

- **Total Questions:** 60 multiple-choice questions.
- **Time Limit:** 45 minutes.
- **Integrity Guideline:** Choose the single best answer for each question. Do not look ahead at the answer key.

| Raw Score | CEFR Band | Proficiency Level | Recommended Knowledge Base Action |
| :-: | :-: | :--- | :--- |
| **55 – 60** | **C2** | **Mastery / Publication-Grade** | You possess native-equivalent grammatical precision. Ready to author RFCs, technical books, and executive whitepapers. |
| **48 – 54** | **C1** | **Advanced Operational Fluency** | Highly effective technical communicator. Polish fine nuances in Module 12 (Advanced Syntax) and Module 15 (Practical English). |
| **40 – 47** | **B2** | **Upper-Intermediate** | Solid operational foundation. Review Module 03 (Tenses), Module 09 (Passive Voice), and Module 10 (Conditionals). |
| **30 – 39** | **B1** | **Intermediate** | Functional but error-prone. Systematic review required in Module 02 (Verbs), Module 04 (Nouns & Articles), and Module 07 (Prepositions). |
| **< 30** | **A1–A2** | **Elementary / Foundation** | Significant grammatical gaps. Work systematically through Modules 01 to 08 following the 12-Week Study Roadmap. |

## 2. The 60 Diagnostic Questions

### Section 1: Foundations, Parts of Speech & Syntax (Q1–Q6)

**1.** Identify the grammatical function of the bracketed phrase: *“[Running out of memory], the container was terminated by the Linux kernel.”*  
(A) Gerund subject  
(B) Dangling participial phrase  
(C) Prepositional complement  
(D) Finite main clause  

**2.** Which of the following sentences correctly repairs the comma splice: *“The build failed, we rolled back the release.”*?  
(A) The build failed, however, we rolled back the release.  
(B) The build failed; therefore, we rolled back the release.  
(C) The build failed we rolled back the release.  
(D) The build failed, so therefore we rolled back the release.  

**3.** In the sentence *“The team delivered the client a robust microservice,”* the noun phrase *“the client”* functions as:  
(A) Direct Object  
(B) Indirect Object  
(C) Subject Complement  
(D) Object Complement  

**4.** Which sentence demonstrates correct grammatical parallelism?  
(A) The engineer is responsible for writing tests, code review, and to deploy containers.  
(B) The engineer is responsible for writing tests, reviewing code, and deploying containers.  
(C) The engineer is responsible for writing tests, to review code, and deploying containers.  
(D) The engineer is responsible to write tests, reviewing code, and deployment.  

**5.** Which punctuation mark must precede a conjunctive adverb (*however, therefore*) when conjoining two independent clauses?  
(A) Comma  
(B) Semicolon  
(C) Em-dash  
(D) Hyphen  

**6.** Which sentence adheres to standard English capitalization and spelling?  
(A) The Google Cloud platform complies to SOC2 Security Standards.  
(B) The Google Cloud Platform complies with SOC2 security standards.  
(C) The Google cloud platform complies to soc2 security standards.  
(D) The Google Cloud platform complies with Soc2 Security standards.

(A) was

## 3. Comprehensive Diagnostic Answer Key & Explanations

| Q# | Key | Grammatical Concept & Diagnostic Explanation | Relevant Module |
| :-: | :-: | :--- | :--- |
| **1** | **B** | **Dangling Participle:** The logical agent of *running out of memory* is the container, but it is placed in passive voice, making the participial modifier grammatically dangle. | Module 16 / 01 |
| **2** | **B** | **Comma Splice Repair:** Two independent clauses joined by *therefore* require a semicolon before and a comma after. | Module 16 / 08 |
| **3** | **B** | **Indirect Object:** *The client* is the recipient of the direct object (*a robust microservice*). | Module 01 |
| **4** | **B** | **Parallelism:** All three items in the series share the identical gerund form (*writing, reviewing, deploying*). | Module 16 / 01 |
| **5** | **B** | **Semicolon Rule:** Conjunctive adverbs joining independent clauses must be preceded by a semicolon. | Module 01 / 14 |
| **6** | **B** | **Preposition & Capitalization:** *Comply* takes *with*; proper project nouns are capitalized (*Google Cloud Platform*). | Module 01 / 07 |
| **7** | **B** | **Concord:** The head subject is singular *list*; intervening plural *IP addresses* does not change agreement. | Module 02 / 16 |
| **8** | **B** | **Proximity Concord:** In *neither...nor*, verb agrees with the closer plural noun *developers* ($\rightarrow$ *were*). | Module 02 |
| **9** | **C** | **Stative Verbs:** *Belong* denotes state/ownership and cannot take continuous aspect (*is belonging* ❌). | Module 02 |
| **10**| **B** | **Gerund Complementation:** *Suggest* strictly takes a gerund complement (*suggested rewriting*). | Module 11 / 13 |
| **11**| **B** | **Passive Modality:** Modal passive formula is `modal + be + V3` (*must be approved*). | Module 02 / 09 |
| **12**| **B** | **The Pronoun Sandwich Rule:** Personal pronouns must go between verb and particle (*spin it up*). | Module 14 / 02 |
| **13**| **B** | **Indefinite Pronouns:** *Everyone* is grammatically singular and takes 3rd-person singular *has*. | Module 05 / 02 |
| **14**| **A** | **Lump-Sum Quantities:** Monetary sums functioning as a collective entity take a singular verb (*is*). | Module 02 / 04 |
| **15**| **C** | **Present Perfect Continuous:** Ongoing duration starting in the past and continuing now takes *has been working*. | Module 03 |
| **16**| **B** | **Intransitive Passive Invariant:** *Occur* is intransitive and cannot form a passive (*was occurred* ❌). | Module 09 / 13 |
| **17**| **B** | **Past Simple:** Definite past time marker *yesterday evening* strictly demands Past Simple (*completed*). | Module 03 / 13 |
| **18**| **B** | **Past Perfect:** Action completed before another past event (*before the alert fired*) requires *had crashed*. | Module 03 / 13 |
| **19**| **A** | **Past Continuous + Past Simple:** Point-in-time interruption (*timed out*) during background state (*was syncing*). | Module 03 / 13 |
| **20**| **B** | **Future Time Clause:** Subordinate time clauses after *when* use Present Simple (*is released*) for future events. | Module 03 |
| **21**| **B** | **Be Going To:** Present physical evidence of an imminent event (*Look at metrics!*) takes *be going to*. | Module 03 / 13 |
| **22**| **B** | **Future Perfect:** Action to be completed before a future deadline (*by next Friday*) requires *will have finished*.| Module 03 |
| **23**| **B** | **Uncountable Mass Nouns:** *Software* is strictly uncountable; it never takes *a* or *-s*. | Module 04 / 16 |
| **24**| **C** | **Uncountable Noun:** *Information* is uncountable; plural *informations* does not exist in standard English. | Module 04 / 16 |
| **25**| **B** | **A Few vs. Few:** Positive small quantity enabling an action requires *a few* (contrast: *few* = shortage). | Module 05 / 13 |
| **26**| **B** | **Possessive Determiner:** Possessive is **its** (no apostrophe); **it's** is a contraction of *it is*. | Module 05 / 16 |
| **27**| **B** | **Objective Pronoun Case:** Preposition *between* governs objective pronouns (*between you and me*). | Module 05 / 16 |
| **28**| **A** | **Singular Profession Rule:** Singular countable professions strictly demand indefinite article *a* or *an*. | Module 04 / 16 |
| **29**| **D** | **Zero Article with Environments:** Computing environments (*production, staging*) take the zero article. | Module 04 / 16 |
| **30**| **B** | **Fewer vs. Less:** Plural countable noun *outages* requires quantifier *fewer*. | Module 05 / 13 |
| **31**| **B** | **Dependent Preposition:** The verb *comply* strictly takes preposition *with* (*comply with*). | Module 07 / 16 |
| **32**| **A** | **Topological Preposition:** Enclosed volumetric computer storage takes *in memory* (contrast: *on disk*). | Module 07 / 13 |
| **33**| **C** | **Preposition of Port / Address:** Network ports take *at port 443* (or *on port 443*). | Module 07 / 13 |
| **34**| **B** | **Adjective + Preposition:** *Capable* strictly takes *of + gerund* (*capable of processing*). | Module 07 / 11 |
| **35**| **B** | **Adverb Formation:** *Fastly* does not exist; *rapidly* is standard. | Module 06 / 16 |
| **36**| **B** | **Unless Invariant:** *Unless* means *except if / if not*. | Module 08 / 10 |
| **37**| **B** | **Resultative Thereby:** Formula is `thereby + V-ing` (*thereby reducing*). | Module 14 |
| **38**| **B** | **Exemplification Standard:** Formal technical writing uses *such as* for category members (not *like*). | Module 13 / 15 |
| **39**| **C** | **Intransitive Verbs:** *Disappear* is intransitive and has no passive voice form. | Module 09 / 13 |
| **40**| **A** | **Reported Speech:** Indirect statement uses standard affirmative order *they must roll back*. | Module 09 |
| **41**| **B** | **Embedded Indirect Question:** Inversion is forbidden; word order is `Subject + Verb` (*where the file is*). | Module 09 / 15 |
| **42**| **B** | **Negative Inversion:** Fronted negative adverbial *Under no circumstances* triggers auxiliary inversion. | Module 12 |
| **43**| **B** | **Only After Inversion:** Fronted *Only after* triggers auxiliary inversion in the main clause (*did we merge*). | Module 12 |
| **44**| **B** | **Mandative Subjunctive:** *It is imperative that* requires the base verb bare infinitive (*sign*). | Module 12 |
| **45**| **A** | **It-Cleft Sentence:** Formula is `It was + Focus + that + Verb` (*triggered*). | Module 12 |
| **46**| **B** | **Zero Conditional:** Present Simple in both clauses for operational rules (*detects $\rightarrow$ dispatches*). | Module 10 |
| **47**| **B** | **Second Conditional:** Hypothetical present uses Past Simple in *if*-clause (*implemented*). | Module 10 |
| **48**| **B** | **Third Conditional:** Unreal past counterfactual uses `had + V3` in *if*-clause (*had configured*). | Module 10 / 15 |
| **49**| **A** | **Inverted Third Conditional:** Drop *if* and invert *had* with the subject (*Had the circuit breaker tripped*). | Module 10 / 12 |
| **50**| **B** | **Stop Doing vs Stop To Do:** Terminating an ongoing action requires gerund *inspecting*. | Module 11 / 13 |
| **51**| **B** | **Preposition 'To' Invariant:** *Look forward to* has prepositional *to*, demanding gerund *receiving*. | Module 11 / 13 |
| **52**| **B** | **Try Doing vs Try To Do:** Testing an experimental solution requires gerund *increasing*. | Module 11 / 13 |
| **53**| **B** | **Affect vs. Effect:** Noun meaning outcome or result is *effect* (RAVEN rule). | Module 14 / 13 |
| **54**| **B** | **Ensure vs. Assure:** Making certain of a system outcome requires *ensure*. | Module 14 / 16 |
| **55**| **B** | **Discrete vs. Discreet:** Distinct, separate entities are *discrete* (spelled with `e` separated by `t`). | Module 14 |
| **56**| **B** | **Principal vs. Principle:** Fundamental design rule or axiom is *principle*. | Module 14 |
| **57**| **C** | **RFC 2119 Standard:** *MUST* denotes an absolute, non-negotiable protocol requirement. | Module 15 |
| **58**| **C** | **Imperative Commit Rule:** Git commit titles must be active imperatives without trailing period (*Fix memory leak*). | Module 15 |
| **59**| **B** | **Would You Mind Response:** Agreeing to help requires *Not at all!* (*Yes* means you object). | Module 15 |
| **60**| **C** | **Blameless Postmortem:** Uses passive voice agent suppression to focus on system failure, not human blame. | Module 15 / 09 |
